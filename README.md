# US_Helathcare_Case_Study
## Objective:
This project analyzes a US healthcare dataset containing patient demographics, admission details, medical conditions, billing information, and insurance data from 100 hospitals. The objective is to derive actionable insights for healthcare executives through data cleaning, exploratory data analysis, visualization, and business recommendations.
## Dataset Used:
<a href="https://github.com/Deepak-NEGII/Data_Analysis_Dashboard/blob/main/Healthcare_Data_v1%20(1).csv">Dataset</a>
## Questions
- Analyze medical condition prevalence across demographic groups.
- Identify key factors affecting patient healthcare costs and suggest cost optimization strategies.
- Analyze admission trends and provide recommendations for hospital resource planning and workload management.

## Process
- Verify data for any missing values and anomalies, and sort out the same.

- Created pivot tables according to the questions asked.
